# 思维链 MindLink

无需登录的在线思维导图与卡片式写作工具，数据本地存储不上云，安全隐私有保障。

在无限画布上自由链接思维卡片，支持时间片段写作、目标整理、小说创作分镜、演讲稿编排、AI 提示词管理等场景。

**在线体验：[https://mindlink.qidianiu.com/](https://mindlink.qidianiu.com/)**

## 功能特性

- **无限画布** — 自由拖拽平移、滚轮缩放，触屏双指缩放，右下角小地图快速定位
- **卡片节点** — 拖拽定位、调整尺寸、双击编辑标题与正文，自动编号
- **双类型连线** — 兄弟连线（链式顺序）与父子连线（层级从属），带合法性校验防环路
- **智能布局** — 拖拽对齐辅助线、重叠自动排斥、链条整体拖拽与旋转
- **多文档管理** — 创建、切换、重命名、删除，每文档独立数据
- **演示模式** — 按 DFS 顺序全屏展示卡片，支持翻页与前后预览
- **数据导入导出** — JSON 格式导出/导入，方便备份与迁移
- **本地存储** — 数据持久化至 localStorage，不上云、无需登录
- **多端适配** — 响应式设计，支持桌面端与移动端触控操作

## 技术栈

| 层面 | 技术 |
|------|------|
| 框架 | Vue 3 (Composition API) |
| 构建 | Vite 8 |
| 状态管理 | 自定义 Composable（reactive/ref） |
| 图标 | Bootstrap Icons |
| 数据持久化 | localStorage |

## 项目结构

```
src/
├── App.vue                    # 根组件
├── main.js                    # 入口文件
├── components/
│   ├── InfiniteCanvas.vue     # 核心画布组件，交互逻辑
│   └── CardNode.vue           # 卡片节点组件，渲染与编辑
├── stores/
│   └── useCanvasStore.js      # 状态管理与数据持久化
└── styles/
    └── animations.css         # 全局动画变量与关键帧
```

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

## 操作说明

| 操作 | 方式 |
|------|------|
| 平移画布 | 鼠标拖拽空白区域 / 触屏单指滑动 |
| 缩放画布 | 滚轮 / 触屏双指缩放 |
| 新建卡片 | 双击画布空白处 / 点击工具栏 + 按钮 |
| 编辑卡片 | 双击卡片 |
| 连线（兄弟） | 点击卡片左侧粉色连接点，再点击目标卡片 |
| 连线（父子） | 点击卡片左侧蓝色连接点，再点击目标卡片 |
| 删除连线 | 点击连线 |
| 微调位置 | 选中卡片后按方向键（Shift 加速） |
| 链内导航 | Ctrl + 方向键 |
| 删除卡片 | 选中后按 Delete 键 / 点击卡片删除按钮 |
| 演示模式 | 点击工具栏演示按钮，方向键或空格翻页，ESC 退出 |
